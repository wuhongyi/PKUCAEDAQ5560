##################################################
程序安装
##################################################


============================================================
Linux
============================================================

本程序安装要求依赖 Qt5、libzmq5 等第三方库。

  
**本程序测试过的系统包含 Ubuntu20.04。 支持各种 LINUX 操作系统编译。如果您的操作系统编译不通过请联系吴鸿毅。**

.. code-block:: bash

  # Ubuntu 依赖安装
  sudo apt -y install build-essential cmake qtbase5-dev python3 libzmq5


  

----------------------------------------------------------------------
软件安装步骤
----------------------------------------------------------------------


* 删除个人目录下的老版本 PKUCAENDAQ5560 文件夹
* 将本程序包解压缩到个人目录中($HOME)



* 编译 GUI 软件

.. code-block:: bash
  
  cd GUI5560
  qmake .
  make 
  # 等待编译结束，编译通过之后，文件夹内将生成可执行文件 gddaq5560
  # 检查是否生成可执行文件 gddaq5560, 如有则编译成功。如果没有，请联系吴鸿毅。
