# A general-purpose digital data acquisition system(GDDAQ-CAEN 5560)

![Yi logo](Yilogo100.png)

English | [简体中文](https://github.com/wuhongyi/PKUCAENDAQ5560/blob/main/README_zh.md)


This program supports the CAEN digital data acquisition modules (5560), currently including R5560B. 

**Supports Linux and Windows systems.**

** If you need the GUI source code, please contact Hongyi Wu(wuhongyi@qq.com / wuhongyi@pku.edu.cn).**
