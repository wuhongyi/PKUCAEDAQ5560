# A general-purpose digital data acquisition system(GDDAQ-CAEN 5560)

![Yi logo](Yilogo100.png)

[English](https://github.com/wuhongyi/PKUCAENDAQ5560/blob/main/README.md) | 简体中文

本程序支持 CAEN 数字化采集卡(5560，目前包括 R5560B。

**支持 LINUX 和 Windows 系统。**

**建议大家及时下载最新版本。**

## 版本
